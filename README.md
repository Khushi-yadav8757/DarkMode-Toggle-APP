# 🌙 Dark Mode Toggle Web App

A modern **Dark Mode Toggle Web Application** built using **HTML, CSS, and JavaScript**.  
This app allows users to easily switch between **Light Mode and Dark Mode** with smooth UI transitions.

The selected theme is stored using **LocalStorage**, so the theme remains saved even after refreshing the page.

This project was created during my **Full Stack Web Development training in college while learning JavaScript**.

---

## 🚀 Features

✔ Light & Dark Mode Toggle  
✔ Smooth animated toggle switch  
✔ Theme preference saved using LocalStorage  
✔ Modern UI with gradient design  
✔ Clean card layout  
✔ Fully responsive design (Mobile + Desktop)

## ⚙ How It Works

1️⃣ User clicks the **toggle switch**  
2️⃣ JavaScript changes the **theme class on the body**  
3️⃣ CSS applies the **light or dark styles**  
4️⃣ Selected theme is stored in **LocalStorage**  
5️⃣ When the page reloads, the saved theme is automatically applied
